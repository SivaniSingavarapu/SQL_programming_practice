# SQL_programming_practice
This repository contains my SQL practice and learning journey, covering SQL fundamentals, data manipulation, aggregation, joins, window functions, and stored procedures.

The purpose of this repository is to strengthen my SQL skills through practical queries and exercises that are relevant to Data Analyst and entry-level software roles.
